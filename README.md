# Najma Akter Lopa — Academic Portfolio

A responsive academic portfolio website designed for university lecturer, research, and academic collaboration applications.

## Files
- `index.html` — main website
- `style.css` — responsive design and layout
- `script.js` — mobile menu, back-to-top button, dynamic year
- `assets/profile.jpg` — supplied profile photo

## Run locally
Open `index.html` in a browser.

## Publish for free
You can deploy this folder using GitHub Pages, Netlify, or Vercel.

## Notes
The content is based on the supplied CV. Update the links/contact information whenever your public profiles or academic status changes.
